# Across the Realms — RPG Rulebook

A rules-light tabletop RPG about travellers who move between worlds.
Characters are described by four columns rated **1–4**: **Body**, **Stuff**,
**Skills**, and **Magic**. Rank travels with you between realms; meaning is
local to each setting.

## Building

Requires [Tectonic](https://tectonic-typesetting.github.io/) (installed).
Tectonic auto-downloads all LaTeX packages and fonts on first build.

```bash
./build.sh          # → rulebook.pdf
# or:
tectonic -X compile rulebook.tex
```

> Note: the machine has no `lualatex` wrapper, so this project targets the
> XeTeX engine via Tectonic. It uses `fontspec` (Libertinus + TeX Gyre
> Adventor) and is functionally equivalent to a LuaLaTeX build for this book.

## Layout

The title page and table of contents are single-column; **`\twocolumn` kicks
in at `\mainmatter`**, so all chapters after the ToC are two-column. Rank
tables use `tabularx` with the custom `Y` column so text wraps cleanly in the
narrower measure.

```
rulebook.tex          Main file: title page, TOC, \twocolumn, \include of chapters.
atrpg.sty             All styling: fonts, colours, headings, boxes, rating pips.
chapters/
  00-intro.tex              The Realms (intro)
  01-character-creation.tex Character Creation (the four columns + priority method)
  02-body.tex              ─┐
  03-stuff.tex             ├ One chapter per column
  04-skills.tex            │
  05-magic.tex            ─┘
  06-high-fantasy.tex      ─┐
  07-cyberpunk.tex         ├ One chapter per genre (each re-themes the page)
  08-space-adventure.tex   ─┘
```

## The Priority Matrix

Character creation uses a Shadowrun-style **priority grid**: assign one of
**A, B, C, D** to each column (Body, Stuff, Skills, Magic), no repeats.
A = top rank (4 pips) down to D = lowest (1 pip). The matrix in
`chapters/01-character-creation.tex` spans both columns via
`\twocolumn[<top material>]`, which leads a fresh page full-width and then
resumes two-column text below it.

> **Gotcha:** inside `\twocolumn[...]` never use a bracketed `\\[2pt]` — the
> literal `]` terminates the optional argument early. Use `\par` + `\vspace`
> for spacing, and plain `\\` for table rows.

## Art

Illustrations live in `art/` as transparent PNG cut-outs, placed in chapters
with `\chapterart{file}`. They're generated by `art/gen.py`, which calls
OpenAI **gpt-image-1** with a single shared `STYLE` string (the source of
visual consistency) and native transparent backgrounds.

```bash
# Key goes in art/.env (gitignored):  OPENAI_API_KEY=sk-...
python art/gen.py art/prompts.jsonl --quality high      # column icons + genre emblems
python art/gen.py art/cover.jsonl   --quality high --size 1024x1536
```

Notes: iterate at `--quality low` (cheap), render finals at `high`. Prompt
figures as "fully armored/clothed" — suggestive phrasing trips moderation.
To restyle the whole book, edit `STYLE` in `gen.py` and regenerate.

## Editing

- **Real rules content** (the 1–4 rating tables, the Shadowrun-style priority
  method, "Magic is whatever makes a setting feel fantastic") is written out.
- **Everything else is `\lipsum` placeholder** prose. Search for `\lipsum`
  and `% TODO` to find what still needs writing.

### Design elements (from `atrpg.sty`)

- `\rating{n}` — the 1–4 pip scale, coloured with the current realm accent.
- `statblock`, `sidebar`, `readaloud`, `example` — themed boxes.
- `\keyword{...}`, `\dice{...}` — inline emphasis helpers.
- **Per-realm theming:** a genre chapter calls
  `\renewcommand{\realmaccent}{colourname}` and every heading, box border,
  and rating pip re-colours to that world's palette.
